01 · MULTI-AGENT · HEALTHCARE

TrialMatch: Privacy-Preserving Multi-Agent Clinical Trial Matching

  • Six-stage LangGraph pipeline (profiler, pre-filter, rule checker, eligibility checker, critic, ranker) on a local Qwen2.5-3B via Ollama, so patient notes never leave a CPU-only 8 GB laptop.
  • Two-tier privacy boundary enforced in code: only public ClinicalTrials.gov text reaches Gemini, verified by a pytest suite that scans the codebase for cloud SDK imports.
  • Hybrid RAG (BM25 + nomic-embed-text with Reciprocal Rank Fusion) over 237 trials and a 44-card medical KB: 0.831 nDCG@10 vs 0.712 for BM25 on held-out TREC 2021 patients.
  • Pre-registered evaluation with SHA-256 code freeze, paired bootstrap CIs and Wilcoxon tests; error analysis of 1,252 criterion decisions pinpointed evidence quoting and temporal reasoning as the bottlenecks.

02 · PATENT · COMPUTER VISION

Concrete Crack Detection Using a Hybrid Deep Learning Framework

  • 96.8% accuracy and 0.98 AUC-ROC across binary and multi-class crack severity tasks (Patent 410906-001).
  • Fused ~9,216-d features from InceptionV3, ResNet50, DenseNet and VGG (18 to 29 ms per image on GPU), classified with SVM / XGBoost at 97% F1 in under 2 ms.
  • Estimates crack depth within ±0.4 mm in under five seconds across 3,000+ images.

03 · AGENT TOOLING

Remote Human-in-the-Loop Approval System for AI Coding Agents

  • Intercepts Claude Code permission requests through a PermissionRequest hook and routes them to a phone for real-time Approve / Deny.
  • FastAPI relay with API-key auth, request TTL expiry, idempotent decisions (409 on duplicates), rate limiting and asyncio long-polling, so it works with no inbound network access.
  • Fail-safe hook that never auto-approves: timeouts and outages fall back to the terminal prompt, with secret redaction before data leaves the machine. Tested with pytest, containerized with Docker.
